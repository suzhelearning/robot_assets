# Task Bin Visual Assets

These normalized OBJ meshes are visual-only bin/container assets for tabletop
sorting and placement tasks. They are paired with primitive collision geoms in
the scene XMLs for stable MuJoCo physics.

## Sources

- `stackable_box.obj`
  - Source: Stackable Plastic Boxes by AleixoAlonso
  - URL: https://sketchfab.com/3d-models/stackable-plastic-boxes-6b1351c3ed8248569c591b1f8c82be9e
  - License: Creative Commons Attribution 4.0
  - Notes: exported from one box mesh in the source FBX and normalized to a unit footprint.

- `low_poly_plastic_crate.obj`
  - Source: Low Poly Plastic Crates by Nodeaxis Interactive
  - URL: https://sketchfab.com/3d-models/low-poly-plastic-crates-7be25030234349508f50e43f1a41abfb
  - License: Creative Commons Attribution 4.0
  - Notes: exported from one connected crate component in the source FBX and normalized to a unit footprint.
