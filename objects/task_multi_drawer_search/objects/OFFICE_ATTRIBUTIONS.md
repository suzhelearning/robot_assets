# Office Object Set Attributions

The office object set uses transformed copies of the assets below. Meshes were
reoriented, centered, uniformly scaled into meters, and paired with simplified
task-specific collision geometry. Textures were resized to at most 1024 pixels.

## Google Scanned Objects

License: [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)

- `scissors/scissors_gso`: `Diamond_Visions_Scissors_Red` from
  [Google Scanned Objects](https://github.com/kevinzakka/mujoco_scanned_objects/tree/main/models/Diamond_Visions_Scissors_Red).
- `tape_roll/tape_roll_gso`: `3M_Vinyl_Tape_Green_1_x_36_yd` from
  [Google Scanned Objects](https://github.com/kevinzakka/mujoco_scanned_objects/tree/main/models/3M_Vinyl_Tape_Green_1_x_36_yd).
